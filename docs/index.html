用户指南 / User Guide

MerkleClaw 加密资产威胁情报调查工具完整使用手册

1

安装 / Installation

macOS

  1. 从官网下载最新 .dmg 安装包
  2. 双击打开 DMG 文件
  3. 将 MerkleClaw.app 拖拽到 Applications 文件夹
  4. 首次打开时，右键选择"打开"以通过 Gatekeeper 验证

Windows

  1. 从官网下载 .msi 或 .exe 安装程序
  2. 双击运行安装向导，按提示完成安装
  3. 安装完成后从"开始菜单"启动 MerkleClaw

首次启动 / First Launch

2

API Key 配置

MerkleClaw 需要链上数据源的 API Key 来获取地址活动信息。点击界面右上角的 设置 ⚙️ 按钮进入配置页面。

Etherscan API Key 必填

一个 Etherscan API Key 即可覆盖 6 条 EVM 链：Ethereum、BSC、Polygon、Arbitrum、Optimism、Base。

获取步骤

  1. 访问 https://etherscan.io 并注册账号
  2. 进入 API Keys 页面，点击 Add
  3. 复制生成的 Key，粘贴到 MerkleClaw 设置中

费用：免费（Free plan 提供 5 calls/sec，足够个人使用）

Helius API Key 可选

用于 Solana 链上数据查询。如需调查 Solana 地址，请前往 https://helius.dev 注册获取。

TronGrid API Key 可选

用于 TRON 链上数据查询。前往 https://www.trongrid.io 注册获取。

第一次调查 / First Investigation

粘贴地址

在顶部搜索栏中粘贴任何区块链地址（支持 EVM、Solana、TRON 格式）。

0x742d35Cc6634C0532925a3b844Bc9e7595f2BD38

自动链检测 / Auto Chain Detection

MerkleClaw 会自动识别地址所属区块链，无需手动选择：

  • 0x... → EVM 链（自动检查活跃链）
  • T... → TRON
  • Base58 编码 → Solana

风险评分 / Risk Score (0–100)

MerkleClaw 从 7 个维度综合评估地址风险：

维度说明
🔗 交易模式异常交易频率与金额
🕸️ 关联网络与已知风险地址的关联度
⏱️ 时间特征活跃时间段异常性
💰 资金流向混币器 / 跨链桥使用情况
🏷️ 标签匹配已知黑名单 / 制裁名单命中
📊 资产构成代币持仓多样性与可疑代币
🤖 行为建模AI 模型行为异常检测

■ 0–30 低风险  ■ 31–60 中等  ■ 61–80 高风险  ■ 81–100 极高

切换标签页 / Tabs

调查界面提供 4 个标签页：

  • Overview — 地址概览、余额、风险评分
  • Graph — 交易关系图谱可视化
  • AI — AI 自动调查分析结果
  • Report — 结构化调查报告

AI 自动调查 / AI Auto Investigation

点击 AI 标签页后，MerkleClaw 将自动执行 7 步深度调查：

  1. 地址画像构建 — 收集基本信息、余额、交易量
  2. 交易历史分析 — 扫描完整交易记录
  3. 关联地址发现 — 识别高频交互地址
  4. 资金流追踪 — 追踪大额资金来源与去向
  5. 模式识别 — 检测洗钱、钓鱼等常见模式
  6. 风险评估 — 7 维度综合评分
  7. 报告生成 — 输出结构化调查结论
4

导出报告 / Export Report

生成报告

  1. 完成调查后，切换到 "导出报告" 标签页
  2. 填写案件信息（案件编号、调查员、备注）
  3. 预览并编辑 AI 生成的调查摘要
  4. 点击 "生成 PDF" 按钮导出

报告内容包含

  • 地址基本信息与风险评分
  • 7 维度风险雷达图
  • 关键交易记录
  • 关联地址网络图
  • AI 调查结论
  • Merkle 验证哈希（防篡改）

报告验证 / Verify Report

每份报告包含唯一的 Merkle 哈希值。任何人都可以在以下地址验证报告真实性：

https://merkleclaw.com/verify/

上传 PDF 文件即可验证其完整性，确保报告未被篡改。

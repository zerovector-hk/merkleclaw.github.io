MerkleClaw Documentation

Crypto-forensics investigation tool — trace, score, and report on-chain activity.

Chapter 1 · Installation

macOS

  1. Go to the GitHub Releases page.
  2. Download the latest .dmg file.
  3. Open the DMG and drag MerkleClaw into your Applications folder.
  4. Launch MerkleClaw from Applications or Spotlight.
Tip: If macOS shows "unidentified developer", go to System Settings → Privacy & Security and click Open Anyway.

Windows

  1. Go to the GitHub Releases page.
  2. Download the .msi or .exe installer.
  3. Run the installer and follow the on-screen prompts.
  4. Launch MerkleClaw from the Start Menu or Desktop shortcut.

System Requirements

PlatformMinimum Version
macOS12 Monterey or later
Windows10 (64-bit) or later

You will also need an Etherscan API Key (free) to query EVM-compatible chains. See Chapter 2 for details.

First Launch

On first launch, MerkleClaw opens an onboarding guide that walks you through entering your API keys and configuring preferences. Follow the prompts to get started in under two minutes.

Chapter 2 · API Key Setup

MerkleClaw uses external API keys to fetch on-chain data. Open Settings ⚙️ to enter your keys.

Etherscan API Key Required

  1. Create a free account at etherscan.io/myapikey.
  2. Generate an API key.
  3. Paste it into Settings → Etherscan API Key.
One key, six chains. A single Etherscan key covers Ethereum, BSC, Polygon, Arbitrum, Optimism, and Avalanche via their shared explorer APIs.

Helius API Key Optional

Required only if you investigate Solana addresses.

  1. Sign up at helius.xyz.
  2. Generate an API key from your dashboard.
  3. Paste it into Settings → Helius API Key.

TronGrid API Key Optional

Required only if you investigate TRON addresses.

  1. Sign up at trongrid.io.
  2. Create an API key.
  3. Paste it into Settings → TronGrid API Key.

Chapter 3 · Your First Investigation

Search an Address

Paste any blockchain address into the search bar at the top of the window. MerkleClaw's smart detection automatically identifies the chain:

Prefix / FormatDetected Chain
0x… (42 chars)Ethereum / EVM
1… or 3… or bc1…Bitcoin
Base58 (32–44 chars)Solana
T… (34 chars)TRON

Risk Score

Every address receives a Risk Score from 0 (clean) to 100 (critical), computed across seven dimensions:

#DimensionWhat It Measures
1BlacklistPresence on OFAC, FBI, or exchange blacklists
2Actor MatchLinks to known threat actors or hacking groups
3MixerInteraction with mixing / tumbling services
4Cross-ChainBridge hops designed to obscure fund trails
5BehaviorAnomalous transaction patterns (velocity, fan-out)
6MoneroSwaps to/from privacy coins (XMR, etc.)
7IncidentsConnection to reported scams, exploits, or rug-pulls

Tabs & AI Assistant

Once a search completes, four tabs are available:

  • Overview — Summary card, risk score breakdown, and key metadata.
  • Graph — Interactive flow-of-funds visualization. Drag to explore, scroll to zoom.
  • AI Assistant — Ask natural-language questions about the address. Click "Full Investigation" to trigger an automated 7-step deep analysis that examines every risk dimension and produces a narrative report.
  • Export Report — Generate a professional PDF report (see Chapter 4).

Chapter 4 · Exporting Reports

Generate a PDF Report

  1. Click the Export Report tab.
  2. Fill in the metadata fields:
    • Case Number — your internal reference ID
    • Client Name — the requesting party
    • Analyst — your name or team
  3. Preview and edit the Executive Summary — MerkleClaw auto-generates one, but you can refine it.
  4. Click Generate PDF.
Tamper-proof. Every exported PDF is signed with a SHA-256 hash embedded in its metadata. This lets anyone verify the report hasn't been altered after generation.

Verify Report Integrity

To verify a MerkleClaw report:

  1. Go to merkleclaw.com/verify/.
  2. Upload the PDF or paste its SHA-256 hash.
  3. The page confirms whether the report is authentic and unmodified.

This verification is useful for courts, compliance teams, and third-party auditors who need proof of report integrity.

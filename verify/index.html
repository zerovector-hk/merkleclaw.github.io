🔐 工作原理 / How It Works

每份 MerkleClaw 取证报告都包含 SHA-256 内容哈希。修改报告的任何内容都会产生不同的哈希值，确保文件完整性可验证。
Every MerkleClaw forensic report contains a SHA-256 content hash. Any modification to the report will produce a different hash, ensuring file integrity is verifiable.

📋 如何使用 / How to Use

  1. 打开报告最后一页的数字签名区域
    Open the digital signature section on the last page of the report
  2. 复制 SHA-256 hash 值
    Copy the SHA-256 hash value
  3. 上传报告 PDF 文件
    Upload the report PDF file
  4. 粘贴哈希并点击验证，比较两个哈希值
    Paste the hash and click verify to compare

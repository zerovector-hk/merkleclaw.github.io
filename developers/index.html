Quick Start

Get up and running with MerkleClaw in four steps.

  1. Install MerkleClaw
    Download the latest release from merkleclaw.com and follow the installer for your platform.
  2. Get an Etherscan API Key
    Sign up at etherscan.io and generate a free API key from your account dashboard.
  3. Configure API Key in Settings
    Open MerkleClaw → Settings → API Keys → paste your Etherscan key and hit Save.
  4. Start Investigating
    Navigate to the Dashboard, enter a wallet address, and let MerkleClaw trace the money flow.

API Reference Backend

The MerkleClaw Backend API runs locally on http://localhost:3001.

Authentication

All requests require a JWT Bearer token in the Authorization header:

Authorization: Bearer <your-jwt-token>

Endpoints

GET /api/chain/:chain/balance/:address

Returns the native token balance for the given address on the specified chain.

# Example: Get ETH balance
curl -s http://localhost:3001/api/chain/eth/balance/0xAb5801a7D398351b8bE11C439e05C5B3259aeC9B \
  -H "Authorization: Bearer eyJhbGciOi..."
GET /api/chain/:chain/txlist/:address

Returns the transaction history for the given address, sorted by block number descending.

# Example: Get transaction list
curl -s http://localhost:3001/api/chain/eth/txlist/0xAb5801a7D398351b8bE11C439e05C5B3259aeC9B \
  -H "Authorization: Bearer eyJhbGciOi..."

ThreatLedger API External

Base URL: https://api.threatledger.net/v1

ThreatLedger provides on-chain threat intelligence — flagged addresses, incident reports, actor profiles, and attack patterns.

Endpoints

GET /health

Service health check.

GET /addresses/check

Check if an address is flagged as malicious. Query param: ?address=0x...

GET /incidents

List recent on-chain security incidents.

GET /actors

Known threat actor profiles and attribution data.

GET /patterns

Common attack patterns and signatures.

GET /latest

Latest threat intelligence feed entries.

GET /usage

Your current API usage and quota status.

SDK Examples

Integrate MerkleClaw into your own tooling with these quick-start snippets.

JavaScript

// Check address against ThreatLedger
const res = await fetch(
  "https://api.threatledger.net/v1/addresses/check?address=0x1234...abcd",
  {
    headers: {
      "Authorization": "Bearer YOUR_API_KEY",
      "Content-Type": "application/json"
    }
  }
);

const data = await res.json();
console.log(data.flagged);   // true
console.log(data.risk_score); // 92

Python

# Check address against ThreatLedger
import requests

resp = requests.get(
    "https://api.threatledger.net/v1/addresses/check",
    params={"address": "0x1234...abcd"},
    headers={"Authorization": "Bearer YOUR_API_KEY"}
)

data = resp.json()
print(data["flagged"])     # True
print(data["risk_score"])  # 92

Already Shipped

✅ Complete

The foundation is in place.

🔗 Core Investigation Engine

Multi-chain transaction graph visualization — trace fund flows across Bitcoin, Ethereum, Tron, and BNB Chain with multi-hop path expansion and interactive node selection.

🏷️ Entity Label Library v1

10M+ pre-tagged addresses covering exchanges, sanctioned entities (OFAC SDN), mixers, darknet markets, and known threat actors. Updated weekly.

🤖 AI Address Clustering

Automatically group related wallets controlled by the same entity using heuristic and ML-based analysis. Turn 50 addresses into 1 investigative target.

📄 Forensic Report Export

One-click PDF report generation with complete chain-of-custody metadata, analyst signature, tamper-evident SHA-256 hash, and legal proceeding-compatible formatting.

🗂️ Case Management

Local case file system — organize investigations, attach notes, manage evidence, and run multiple cases simultaneously. All data stays on your machine.

🔒 Offline / Air-Gapped Deployment

Full offline operation for high-security law enforcement environments. Label library distributable via USB media. No internet connection required.

🌀 Mixer Penetration Analysis

Probabilistic linking of pre- and post-mix fund flows using time-window and denomination-matching algorithms. Confidence scoring on all probabilistic links.

❌ Consciously Not Planned

Social Media Tracking / OSINT Integration

We focus on on-chain data. Linking blockchain addresses to social profiles introduces significant privacy and legal complexity we're not ready to navigate responsibly.

Custodial Key Management

MerkleClaw is a tracing tool, not a wallet. We will never touch private keys.

Automated Seizure / Freeze Execution

Identifying assets to freeze is our job. Executing the freeze is law enforcement's job. We provide evidence packages; we don't replace the legal process.
